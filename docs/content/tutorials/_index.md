Each tutorial starts from a working setup and does one real job from start to
finish. They follow the same example researcher, Alex, whose home directory on
the cluster holds data for three grants:

| Grant | What it funds | Directories | Ends |
|-------|---------------|-------------|------|
| `NSF-2231` | Soil carbon dynamics under forest management | `~/soil_carbon`, `~/soil_carbon_runs` | 2027-08-31 |
| `USDA-1180` | Coastal marsh mapping | `~/marsh_mapping` | 2026-06-30 (ended) |
| `EPSCOR-T2` | Forest plot remote sensing | `~/forest_plots` | 2028-05-31 |

The output shown is what stomp printed for Alex. Your sizes, dates and grant
names will differ, but the commands are the same.

If you haven't set up stomp yet, start with the
[quick start](@/getting-started/quick-start.md) or the first tutorial.
